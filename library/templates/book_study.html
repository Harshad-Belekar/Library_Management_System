{% if "Artificial Intelligence" in book.title %}

🤖 1. Introduction to Artificial Intelligence

Artificial Intelligence, commonly called AI, is a branch of computer science that focuses on creating machines and software capable of performing tasks that normally require human intelligence.

AI systems can learn from information, solve problems, understand language, recognize patterns and make decisions.

Remember:

AI aims to make computer systems capable of performing intelligent tasks.

🧠 2. Intelligent Agents

An intelligent agent is a system that observes its environment through sensors and performs actions using actuators.

Examples

  • Self-driving vehicles
  • Voice assistants
  • Recommendation systems
  • Robots
  • Game-playing programs
Example:

A robot can use sensors to understand its surroundings and motors to move.

🔍 3. Problem Solving and Search

AI systems often need to find a solution to a problem. Search algorithms help an AI system explore possible solutions and select an appropriate one.

Common Search Techniques

  • Breadth First Search
  • Depth First Search
  • Uniform Cost Search
  • Greedy Search
  • A* Search

📚 4. Knowledge Representation

Knowledge representation is the process of storing information in a form that an AI system can use for reasoning and decision making.

Knowledge can be represented using rules, facts, relationships and logical structures.

🤖 5. Machine Learning

Machine Learning is an important area of AI where computer systems learn patterns from data instead of being explicitly programmed for every situation.

Types of Machine Learning

  • Supervised Learning
  • Unsupervised Learning
  • Reinforcement Learning

🧬 6. Deep Learning

Deep Learning is a part of machine learning that uses neural networks with multiple layers to learn complex patterns from large amounts of data.

Deep learning is commonly used in image recognition, speech recognition and natural language applications.

💬 7. Natural Language Processing

Natural Language Processing, or NLP, allows computers to process and understand human language.

  • Text classification
  • Language translation
  • Chatbots
  • Speech recognition
  • Sentiment analysis
{% elif "Django" in book.title %}

🌐 1. Introduction to Django

Django is a high-level Python web framework used to build secure, scalable and maintainable web applications.

Django follows the Model-Template-View architecture and provides many features required for web development.

Remember:

Django is built using Python and is mainly used for web application development.

🏗️ 2. Django Project and App

A Django project contains the overall configuration of a website, while an app contains functionality for a particular feature.

Examples of Apps

  • Student Management
  • Library Management
  • Authentication
  • Shopping Cart

🗄️ 3. Models

Models are Python classes used to define the structure of data stored in the database.

Each model generally represents a database table. Model fields represent the information stored in that table.

Example:

A Book model can contain title, author, ISBN, category and quantity.

👁️ 4. Views

Views contain the application logic. A view receives a request, performs required operations and returns a response.

Views can retrieve information from models and send that information to templates.

🎨 5. Templates

Templates are HTML files used to create the user interface of a Django application.

Django Template Language allows dynamic information from views to be displayed inside HTML pages.

🔗 6. URLs

URL patterns connect a browser URL to a particular Django view.

For example, a URL can connect a student dashboard address to the student dashboard view.

📝 7. Forms

Django forms are used to collect information from users and process submitted data.

  • Registration forms
  • Login forms
  • Book forms
  • Test forms
  • Search forms

🗃️ 8. Database

Django provides an Object Relational Mapper, commonly called ORM, which allows developers to work with databases using Python objects.

This reduces the need to write raw SQL for common database operations.

{% elif "Data Science" in book.title %}

📊 1. Introduction to Data Science

Data Science is the process of collecting, cleaning, analyzing and interpreting data to obtain useful information and insights.

It combines programming, statistics, mathematics and analytical techniques.

Remember:

Data Science helps convert raw data into meaningful information.

🐍 2. Python for Data Science

Python is widely used in Data Science because it provides powerful libraries for data manipulation, analysis and visualization.

Important Libraries

  • NumPy
  • Pandas
  • Matplotlib
  • Seaborn

🔢 3. NumPy

NumPy is a Python library used mainly for numerical computing and working with arrays.

It provides efficient operations for mathematical calculations and multidimensional arrays.

🐼 4. Pandas

Pandas is a Python library used for data manipulation and analysis.

Common Pandas Operations

  • Reading CSV files
  • Creating DataFrames
  • Filtering data
  • Grouping data
  • Handling missing values
  • Sorting data

🧹 5. Data Cleaning

Data cleaning is the process of identifying and correcting incomplete, incorrect or inconsistent data.

Common Tasks

  • Handling missing values
  • Removing duplicate records
  • Correcting data types
  • Handling incorrect values

📈 6. Data Visualization

Data visualization represents information using charts and graphs so that patterns and trends can be understood easily.

Common Charts

  • Bar Chart
  • Line Chart
  • Pie Chart
  • Histogram
  • Scatter Plot

📐 7. Statistics

Statistics helps us understand and summarize data. Common statistical measures include mean, median, mode, minimum and maximum.

Example:

The mean represents the average value of a collection of numerical observations.

🤖 8. Machine Learning

Machine Learning allows computers to learn patterns from data and use those patterns to make predictions or decisions.

  • Classification
  • Regression
  • Clustering
