# 📚 Library Management System

A web-based **Library Management System** developed using **Python and Django** to digitally manage books, students, tests, results, and personalized study recommendations.

This system provides separate functionality for **Admin** and **Students**, making library management and student learning activities simple, organized, and efficient.

---

## 📌 Project Overview

The Library Management System is designed to automate common library and student learning activities.

The **Admin** can manage books, students, tests, and questions, while **Students** can browse books, attempt tests, view their results, and receive book recommendations based on their test performance.

The project provides a simple, user-friendly, and responsive interface using **HTML and CSS** with Django as the backend framework.

---

## 🎯 Project Objectives

- Digitize basic library management activities.
- Provide an easy platform to manage books.
- Maintain student information.
- Allow administrators to create online tests.
- Allow students to attempt tests online.
- Automatically calculate test results.
- Display student percentage and performance.
- Recommend books based on student performance.
- Help students find suitable study material.
- Reduce manual library and test management work.

## 📝 Online Test System

The system allows the administrator to create tests for different books or categories.

Students can:

1. Select a test.
2. Read the questions.
3. Select answers.
4. Submit the test.
5. Get the result automatically.
6. View their percentage.
7. Receive recommended books based on their performance.

---
